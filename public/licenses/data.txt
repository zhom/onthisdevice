Data sources and licences: onthisdevice.com reference data
==========================================================

The reference tools on this site use public data sets. A scheduled job downloads each set,
checks it, and stores it with the site as static files under /data/. Your browser reads those
files from this site; a lookup never leaves your device. Each tool page shows its source and
the date of the data.

Fetchers: scripts/data/ in the public repository (github.com/zhom/onthisdevice).


Euro foreign exchange reference rates (currency converter)
  Source:   European Central Bank
            https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/
  Licence:  ECB statistics may be reused free of charge provided the source is acknowledged.
            https://www.ecb.europa.eu/services/disclaimer/html/index.en.html
  Updated:  daily

Cloud and CDN IP ranges (cloud IP lookup)
  Source:   The range files each provider publishes for firewall rules:
            Amazon Web Services   https://ip-ranges.amazonaws.com/ip-ranges.json
            Google Cloud          https://www.gstatic.com/ipranges/cloud.json
            Google                https://www.gstatic.com/ipranges/goog.json
            Microsoft Azure       https://www.microsoft.com/en-us/download/details.aspx?id=56519
            Oracle Cloud          https://docs.oracle.com/en-us/iaas/tools/public_ip_ranges.json
            Cloudflare            https://www.cloudflare.com/ips/
            Fastly                https://api.fastly.com/public-ip-list
            DigitalOcean          https://digitalocean.com/geo/google.csv
            Akamai Cloud (Linode) https://geoip.linode.com/
            Vultr                 https://geofeed.constant.com/
  Licence:  Factual lists that the providers publish for public use. No licence terms
            restrict their redistribution.
  Updated:  weekly

Top-level domains and public suffixes (domain extension lookup)
  Source:   IANA Root Zone Database      https://www.iana.org/domains/root/db
            IANA list of TLDs             https://data.iana.org/TLD/tlds-alpha-by-domain.txt
            Public Suffix List            https://publicsuffix.org/
  Licence:  Root zone data: public factual data published by IANA.
            Public Suffix List: Mozilla Public License 2.0, https://mozilla.org/MPL/2.0/
            The list is converted to JSON (rules unchanged, internationalised labels in

            the file at publicsuffix.org.
  Updated:  monthly
